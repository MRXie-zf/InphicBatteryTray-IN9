## 一句话版本

之前一直在 `mi_02`（in=64/out=64）上用 `WriteFile` 发 33 字节、报告 ID 0、命令 0x10 ——
全错。真实通道是 **Feature Report**：报告 ID `0x0C`、33 字节、命令 `0x20`，
在 `FeatureReportByteLength == 33` 的那个接口（Usage Page `0xFF00`）上
`HidD_SetFeature` → `Sleep(10)` → `HidD_GetFeature`，电量在 `buf[0x12]`。

## 之前的排除项（仍然有效，供参考）

- `mi_02` 的 WriteFile 只回显，所有命令码（0x00–0x3F）均无数据返回
- `mi_02` 上 15 种校验和算法、5 种校验和位置、握手时序变体：全部无效
- Feature Report 报告 ID 0–255 穷举：只有 `0x0C` 可用（那次没试对命令码）
- 被动监听 15 秒：0 帧（Feature Report 不广播，注定抓不到）
- `HidD_GetInputReport`：错误 31
